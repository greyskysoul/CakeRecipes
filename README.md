# 电饭煲戚风蛋糕食谱集

4 份食谱共用一套流程，只有蛋黄糊的口味不一样。

- 用的锅：**米家电饭煲 N1 1.6L**，就用自带的「蛋糕键」
- 烤多久：电饭煲烤制流程约 **1 小时**（备料和晾凉不算在内）
- 记住三件事：蛋白打到硬性发泡；时间宁短不长；中间湿软是正常的，放凉更好吃

## 通用流程

1. 蛋清蛋黄分开，装蛋清的盆要无油无水
2. 做蛋黄糊（看各自食谱）
3. 蛋白打到硬性发泡，大概 3 分钟
4. 先挖 1/3 蛋白糊跟蛋黄糊翻拌，再倒回去，从底下往上翻拌
5. 电饭煲预热 3 分钟 → 按蛋糕键烤约 1 小时 → 表面不粘手就是熟了，倒出来晾凉
